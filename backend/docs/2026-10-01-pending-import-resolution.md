# 待确认导入事务的明确结束操作

新增 `POST /api/v2/imports/:id/resolve`，必须登录且请求体包含布尔值 `confirm_reject_pending: true`。账号、伴侣仍从认证作用域取得，请求体中的伪造身份或决策不会被使用。

`resolveContentImport` 读取所属任务；已经完成则返回计数回执，否则复用 `commit_content_import_atomic`，给全部旧候选提交 rejected 决策。现有任务行锁与决策摘要裁决迟到原提交：放弃先完成则后来的不同决策冲突；原提交先完成则读取并保留原结果。不会创建新导入，也不会删除已保存内容。

世界书运行时字段只在 accepted 时校验，拒绝候选无需提供不会写入的关键词配置。接受世界书时原校验仍保留。

仅完整的 committed 状态、匹配 ID 和安全整数计数可产生 `reject-pending-v1` 回执。网络未知、部分旧记录、旧协议等继续返回精确错误，不声称已安全重置。

本次没有 SQL/schema 修改，不需要生产迁移。测试使用虚构数据库及 HTTP，覆盖两种到达顺序、重复结束、迟到提交、伪造身份、外部账号、异常回执和拒绝世界书候选。实际 PostgreSQL SQL 在 PGlite 中执行；未进行生产多连接争用或真实用户写入验收。
