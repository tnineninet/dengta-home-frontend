# 日常功能独立反馈 2.10.56 / code104

原先日常功能同时读取纪念日、成就和照片，读取异常被转换成 null，并仅根据成就是否成功决定整体状态。照片或纪念日读取失败可能被误显示为空列表，先返回的数据也必须等待较慢的请求。

现在每项独立显示加载状态、错误码、HTTP 状态及日志入口，并可单独重试；已有记录在失败时保留。请求版本按栏目区分，重试照片不会取消其他栏目请求；账号或伴侣切换后，旧请求不能更新数据或触发成就提醒。删除纪念日必须收到匹配记录 ID 的删除回执；等待中避免重复点击，未确认时提示先刷新核对。
